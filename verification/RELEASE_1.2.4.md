# Aiplayed 1.2.4 / Android version code 7

This update responds to device screenshots showing rectangular navbar press feedback, duplicate playlist creation actions and crowded search controls. The navbar uses explicitly clipped patterned backgrounds rather than platform ripple masks. Empty and populated Playlists each expose one centered creation action; list controls have a 12-point search gap.

Sound adjustments use circular gesture controls, not horizontal faders. Reanimated shared values drive the indicator on the UI thread; circular angle deltas cross the wrap boundary without jumps. One gesture previews through the existing serialized DSP controller, commits once on release, and cancels without saving on termination or multitouch. Precision buttons and adjustable accessibility actions use the same limits and step sizes. Sound preset choices stay on Sound. Song-position seeking stays on the player timeline.

The generated multicolour launcher mark uses lavender, peach, mint and blue. Android foreground/legacy vectors reproduce that colour family; monochrome retains a single-colour vinyl/play silhouette. Startup uses its own turntable illustration and full-screen pastel background. It rotates only while initialization/initial scanning is active and motion is allowed. No artificial delay or simulated percentage is added. Initialization errors retain Try again.

Local checks include the full behavior/DSP suite, knob rotation/clamping/precision/cancellation and startup Reduce Motion/recovery. Android CI retains cold-start/interaction recordings, all four navbar press frames, empty/populated playlists, spacing, circular dial rotation in both directions, cancellation, exact increments, playback continuity and persistence after navigation. The existing Lint, package branding/splash, signature and offline-permission gates remain required before publication.
