Aiplayed v1.2.3 (Android version code 6) replaces Library categories and shortcut cards with a labelled + Browse sheet. It remembers each destination's search and scroll position, adds consistent A–Z browsing, restores artwork swipes and uses softer rounded press feedback.

Lavender vinyl/play branding now appears in the launcher and native startup. Initialization respects Reduce Motion and offers recovery after a failure. Sound preset choices remain on the Sound page.

Published after behavior/DSP tests, Expo compatibility checks, native compilation, Android Lint, APK signature/branding/splash/offline-permission checks and Android emulator interactions. Screenshots, recordings and diagnostics are attached to the corresponding GitHub Actions run. A SHA-256 checksum accompanies the APK.
