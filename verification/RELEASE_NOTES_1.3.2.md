Aiplayed v1.3.2 (Android version code 12)

- The playback notification and lock-screen media card receive dedicated square artwork with the ribbon icon's safe padding, instead of relying on Android's launcher-icon fallback.
- About, App permissions and Clear listening history now use app-themed panels. The Aiplayed description reflects the app's offline features and displays the current version.
- Clear history has explicit confirmation, progress and retry states. Music files, favourites, playlists and saved audio analysis are retained.
- Sound's Reset button has a visible themed border.
- Browse, playback and sleep-timer sheets have coloured headers, contrasting actions and clearer selected states in light and dark themes.

Both APK and ZIP downloads are supplied with SHA-256 checksums. Extract the ZIP to install the enclosed APK.

The release is published after APK, interaction, recommendation and Android theme validation passes. Phone manufacturers control media-card layout; emulator checks do not establish the exact appearance on every physical device.
