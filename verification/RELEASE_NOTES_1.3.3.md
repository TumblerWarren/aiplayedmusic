Aiplayed v1.3.3 (Android version code 13)

Personal mixes now learn from actual listening duration, recent interests and observed local-hour/weekday habits alongside the bundled S-SONDO FP32 audio model.

- Distinguish deliberate song choices and replay from shuffle, automatic repeat and recommendation playback.
- Count active listening without pauses or seek jumps; support meaningful listening to long medleys.
- Refresh suggestions as listening habits and local time change, without changing the playing queue.
- Show explanations supported by listening history while retaining separate tastes and artist/album spacing.
- Upgrade existing history storage without re-analysing audio; clearing history also removes routines and ranking weights.

All audio, listening information and learned preferences stay on the phone. No new model download or network permission is added.

Native recommendation and Kotlin bridge checks passed before release preparation. Publication requires the full APK, interaction and Android theme gates. Synthetic evaluation is not proof of real-world relevance or phone performance.

APK and ZIP downloads include SHA-256 checksums. Existing releases are preserved.
